# フォント選定の見直し

## 採用設定

- 本文・UI・見出し：Noto Sans JP。本文400、見出し600、強調700。
- サイト名：Space Mono Boldを維持。
- コード：テーマの等幅フォントを維持。
- 本文サイズ：スマートフォン16px、PC18px。本文行間1.3倍、字間0を維持。
- 読み込み：Google Fonts、`display=swap`。取得できない場合は端末の日本語ゴシックへフォールバックする。

研究から「Noto Sans JPがBIZ UDPゴシックより優れている」とは結論できない。日本語と英語の論文名が混在するブログでの見た目、ウェイトの使い分け、配信方法を含めた実装上の選択として採用した。書体の変更だけで読書速度や理解度が改善したと主張しない。

## 読んだ研究

### 大西まどか・小田浩一（2017）

[スタイルとウェイトが日本語フォントの読みやすさに与える影響](https://www.jstage.jst.go.jp/article/jieij/101/10/101_474/_article/-char/ja/)。照明学会誌101(10), 474–483。[本文PDF](https://www.jstage.jst.go.jp/article/jieij/101/10/101_474/_pdf/-char/ja)。

4スタイル×3ウェイトのゴシック体を、MNREAD-Jに沿った音読時間と誤りで評価した研究。字面の大きさと文字間隔にはトレードオフがあり、一文字の見分けやすさと文章の読みやすさは同一ではない。ウェイトの効果も、特に小サイズで検討されている。

適用：UDという名称だけで選ばず、文章全体の密度と太さを確認する。本文を一律に太字にせず、見出し600と強調700を分ける。研究で本ブログの600という値が最適と示されたわけではない。

### 阿久津洋巳・近藤雄希（2010）

[文字の読みやすさ2：読みやすさと読みの速さの比較](https://www.jstage.jst.go.jp/article/jjsse/14/1-2/14_26/_html/-char/ja)。日本官能評価学会誌14(1–2), 26–33。

MS明朝の文字サイズを変え、主観的な読みやすさと音読速度を別々に評価した研究。両指標は同じ変化を示さず、小さすぎる文字の問題だけでなく、サイズを大きくし続けても良いとは限らないことを扱っている。

適用：好み・快適さと読みの性能を混同せず、本文を安易に縮小しない。実験のptや視角をWebのCSS pxへそのまま移し替えず、16〜18pxは本サイトの設計値として扱う。

### 古川千咲・牛山道雄（2022）

[フォントの違いと視認特性が可読性に及ぼす影響に関する研究](https://www.kyokyo-u.ac.jp/Ccce/8bc9459f518ba066c326e8620d8fa55e94dae06b.pdf#page=18)。京都教育大学総合教育臨床センター研究紀要1, 13–19。

スマートフォンで4書体を主観評価した研究。112名の参加者のうち条件を満たした69名を分析し、UDデジタル教科書体が比較対象より高く評価された。ただし主観評価であり、Noto Sans JPやBIZ UDPゴシックを直接比較した研究ではない。文章理解や速度への効果をそのまま示すものでもない。

適用：細い書体や極端な太字を避け、スマートフォンで文章として確認する。特定のUD書体の結果を、あらゆるUD書体へ一般化しない。

## 書体の仕様

[Noto Sans JPのGoogle Fonts公式メタデータ](https://github.com/google/fonts/blob/main/ofl/notosansjp/METADATA.pb)で、日本語・ラテン文字の対応とウェイト範囲を確認した。読み込むのは実際に使う400・600・700のみ。

## 保守

`assets/css/custom.css` の `--blog-font`、`--blog-weight-heading`、`--blog-weight-bold`、`layouts/partials/extend-head.html` の読み込みを同時に変更する。元のBIZ UDPゴシックは端末にある場合のフォールバック候補として残し、Webフォントとしては二重に読み込まない。

このサイトでの実読者による比較試験は未実施。ブラウザ表示の確認は可読性の優劣を証明する実験ではない。

## 表示確認

ホーム・記事一覧・長文記事・プロフィールを390px／1440pxで表示し、横はみ出しがないことを確認した。Chromeのフォント情報からダウンロードしたNoto Sans JPが日本語段落に使われていることを確認し、プロフィールのh2が600になっていることも検証した。PCとスマートフォンのプロフィールを目視確認した。Hugo Extended 0.169.0でビルド成功。
